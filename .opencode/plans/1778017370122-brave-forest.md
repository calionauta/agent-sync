# README mais enxuto no publish de skills

## Contexto

O `agent-sync skills publish` gera um README.md no repositório público com a listagem das skills publicadas. Atualmente ele extrai os primeiros 500 caracteres de cada SKILL.md como resumo.

O usuário quer um formato mais simples: **apenas os nomes das skills** (bullet list).

## Mudanças

### `src/agent_sync/publish.py`

1. **Simplificar `generate_readme()`** — em vez de seções `### nome` + resumo de 500 chars, gerar uma lista simples:
```markdown
## Skills

- boilerplate-go
- codebase-spec
- docker-server-dashboard
- ...
```

2. **Remover `strip_frontmatter()`** — função não será mais necessária (só era usada pelo `generate_readme`). Pode ser deletada.

### `tests/test_publish.py`

Nenhuma mudança necessária — os testes existentes mockam `Path.write_text`, então não dependem do conteúdo do README.

## Verificação

1. Rodar `pytest tests/test_publish.py` — testes existentes devem continuar passando
2. Rodar `agent-sync skills publish` (non-interactive) — confirmar que o README gerado tem só a bullet list
